## 읽는 순서

| 역할 | 문서 |
|---|---|
| IT 담당 PM / 보안 검토 | 명세서 1~2장 → `개발_인수인계_노트.md` 3장 (보완 필요 사항) |
| 인프라 담당 | `배포가이드.md` |
| 개발 담당 | `개발_인수인계_노트.md` → 명세서 3~4장 |
| QA | 명세서 7장 |

**바로 화면을 보려면**: `01_src/` 폴더를 아무 웹서버(IIS, nginx 등)에 올려 `index.html`을 여세요. `config.js`가 데모모드(`DEMO_MODE = true`)로 되어 있어 DB 없이 샘플 데이터로 동작하고, **이때는 로그인을 요구하지 않습니다.** 외부 인터넷 연결은 필요 없습니다. (파일을 더블클릭해서 열면 브라우저 보안 정책 때문에 일부 아이콘이 안 보일 수 있습니다.)

**운영으로 전환할 때 순서** (`DEMO_MODE = false`):
1. `02_db/01_schema.sql` → `02_storage_bucket.sql` → `03_initial_data.sql` 실행
2. Authentication > Users 에서 팀원 계정 생성 (`Auto Confirm User` 켜기)
3. Authentication > Providers > Email 에서 `Enable email signup` **끄기** (외부인 자가 가입 차단)
4. `config.js`에서 `DEMO_MODE = false`, API 주소·키, `LOGIN_EMAIL_DOMAIN` 입력
5. 로그인 후 데이터가 보이는지, 로그인 없이 `index.html` 직접 접속이 차단되는지 확인

> 2번보다 1번을 먼저 하는 것은 괜찮지만, **계정이 하나도 없는 상태에서 `DEMO_MODE = false`로 두면 아무도 데이터를 볼 수 없습니다.** RLS가 로그인한 사용자만 허용하기 때문입니다 (의도된 동작).
