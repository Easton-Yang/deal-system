**요청 부서**: 자산운용팀 · **요청 내용**: 현업이 만든 딜 관리 웹 시스템을 내부 VDI 환경에 운영 배포
**사용자**: 자산운용팀 4명 (유성훈, 양동민, 신승준, 김민지)
**초기 데이터**: 포트폴리오현황보고 딜 접수목록 2026.1Q·2Q **247건** 이관 (`02_db/03_initial_data.sql`)

---

## 패키지 구성

```
IT전달패키지_v1.0/
├─ 00_README_먼저읽기.md              ← 이 문서
├─ 01_src/                            배포 소스 (웹서버 루트에 그대로 복사)
│   ├─ *.html (화면 5개), css/, js/
│   └─ vendor/                        외부 라이브러리 로컬 사본 (CDN 불필요, SHA256SUMS.txt 포함)
├─ 02_db/
│   ├─ 01_schema.sql                  테이블 4개 + 제약조건 + 인덱스 + 트리거 + RLS 정책(주석)
│   ├─ 02_storage_bucket.sql          첨부파일 버킷
│   └─ 03_initial_data.sql            실제 딜 247건 + 단계이력 440건 (엑셀 이관)
├─ 03_deploy/
│   ├─ fetch-vendor.ps1               라이브러리 내려받기 스크립트 (인터넷 PC에서 실행)
│   ├─ nginx.conf.sample              Linux 웹서버 설정 예시
│   └─ web.config                     Windows IIS 설정 예시
└─ 04_docs/
    ├─ 딜관리시스템_기능요구사항명세서_v1.0.docx   기능 요구사항 · 화면 설명 · DB 설계 · QA 체크리스트
    ├─ 배포가이드.md                  구성도, 서버 사양, 설치 절차, 백업
    └─ 개발_인수인계_노트.md           소스 구조, 데이터 함수 명세, 운영 전 보완 필요 사항
```

## 읽는 순서

| 역할 | 문서 |
|---|---|
| IT 담당 PM / 보안 검토 | 명세서 1~2장 → `개발_인수인계_노트.md` 3장 (보완 필요 사항) |
| 인프라 담당 | `배포가이드.md` |
| 개발 담당 | `개발_인수인계_노트.md` → 명세서 3~4장 |
| QA | 명세서 7장 |

**바로 화면을 보려면**: `01_src/` 폴더를 아무 웹서버(IIS, nginx 등)에 올려 `index.html`을 여세요. `config.js`가 데모모드로 되어 있어 DB 없이 샘플 데이터로 동작합니다. 외부 인터넷 연결은 필요 없습니다. (파일을 더블클릭해서 열면 브라우저 보안 정책 때문에 일부 아이콘이 안 보일 수 있습니다.)
