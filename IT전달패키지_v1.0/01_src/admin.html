데이터 백업 (매주 권장)

무료 요금제라 Supabase가 자동으로 백업해주지 않습니다. 아래 버튼을 누르면 지금 저장된 딜·메모·단계이력·첨부정보·텔레그램 초안 전부를 파일 하나(JSON)로 내려받습니다. 현재 전체를 합쳐도 1MB가 안 돼서 매주 받아도 부담 없습니다. 매주 한 번씩 눌러서 맥북에 보관하는 걸 권장합니다.

데이터 업로드 (최초 1회)

엑셀에서 옮긴 딜 데이터를 Supabase 로 올립니다. 이미 데이터가 있으면 아무 것도 하지 않고 건너뜁니다.

비밀번호 변경
비밀번호는 이 화면에서 바꾸지 않습니다. Supabase 가 비밀번호를 해시(되돌릴 수 없는 형태)로 보관하므로, 관리자도 다른 사람의 비밀번호를 볼 수 없습니다.
  • 본인 비밀번호: 아래 버튼으로 재설정 메일을 받습니다.
  • 팀원 비밀번호 초기화 / 계정 추가·삭제: Supabase 대시보드 → Authentication → Users 에서 처리합니다.
